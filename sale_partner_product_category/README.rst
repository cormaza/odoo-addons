This module automatically synchronizes website product categories
(``product.public.category``) to the customer's tags
(``res.partner.category``) when a Sale Order is approved.

The final purpose is that certain clients to whom certain products have
been sold can be segmented for specific marketing campaigns. The search
and assignment of tags are done by name without matching the full
category tree. Cancelling the sale order will not change the customer's
information.
